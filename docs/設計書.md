# 筋トレ共有アプリ（名前はまだ）設計書

スポーツチームのメンバーが筋トレを記録して、タイムラインで見せ合い、トレーナーがコメントやメニューを届けるアプリ。
最初は自分のチーム（アメフト・選手40人・トレーナー5人くらい）で使い、最終的には ほかのチームにも配る。

- 作成日：2026-10-13／書き直し：2026-10-14
- 状態：**第6版。この設計書に書いた機能は 作り終わっている**（「9. 保留・これから」を除く）
- 確かめたこと：テスト 69件（SQLite と PostgreSQL の両方で 全部通る）・ブラウザでの 一通りの流れ
- まだ確かめていないこと：本物のスマホへの通知・本物の Cloudflare R2（インターネット上に置いてから確かめる）
- 参考にしたもの：`ハビットトラッカー/kintore_app`（記録のしかた・休憩タイマー・通知・置き場所）

---

## 1. このアプリでできること

| だれが | できること |
|---|---|
| 選手 | 筋トレを記録する（種目ごとに「記録の仕方」がちがう）。休憩タイマーを使う。あとから記録する |
| 選手 | 投稿する前に セットの数字を直す。種目ごとに メモを付ける |
| 選手 | 終わった筋トレを、全体のひとこと と 写真（4枚まで）を付けて タイムラインに投稿する。投稿したあとで ひとこと・写真を直す |
| 選手 | みんなの投稿を見る。スタンプ・コメント・返信をする。名前を押して その人の履歴とグラフを見る |
| 選手 | 体重・体脂肪率を記録する（自分とトレーナーだけに見える） |
| 選手 | トレーナーから配られたメニューを見て、そのメニューで記録する |
| トレーナー | まだ見ていない投稿を 受信箱で順番に見て、コメントする |
| トレーナー | メニューを作って、チーム全員か 選んだ人に配る |
| トレーナー | メンバーの一覧（最近やっているか）を見る。チームの管理（招待・役割・競技・種目の直しとまとめ） |

作らないもの：カロリー・食事・基礎代謝・ハビットモンスターとの取りこみ・トレーナーとのチャット（LINE で足りるため。2026-10-14 に見送りと決めた）。

## 2. 全体のしくみ

```
[選手のスマホ]──────┐
[トレーナーのスマホ/PC]─┼─▶ [アプリ本体（Render）] ─┬─▶ [データベース（Neon）]   文字と数字
                   ┘     FastAPI + 画面         └─▶ [写真置き場（Cloudflare R2）] 写真
```

| 部分 | 使うもの | パソコンの中で試すとき |
|---|---|---|
| サーバー | Python + FastAPI + SQLModel | 同じ（`start.bat`） |
| 画面 | HTML / CSS / JavaScript（フレームワークなし）の PWA | 同じ |
| データベース | PostgreSQL（Neon） | SQLite（`data/app.db`） |
| 写真置き場 | Cloudflare R2（S3互換。非公開） | フォルダ（`data/photos`） |
| 通知 | Web Push（pywebpush） | 同じ（パソコンの Chrome・Edge なら届く） |

**いくつものチームで使える形** にしてある（最終的に ほかのチームにも配るため）。

- すべての記録に「どのチームのものか」を付ける。ほかのチームの記録・写真・メンバーは 絶対に見えない
- どのチームかは、ログインしている人から サーバーが決める（画面から チームの番号は 受け取らない）
- 1人のアカウントは 1つのチームに入る

**チームごとの人数の上限**：選手 100人・トレーナー 10人（チームごとに持つので、あとで変えられる）。上限に届いたら 新しい人は登録できない。やめた人を「使えなくする」と 1人分あく。数字を変えるのは 運営（自分）だけで、今は データベースを直接直す。

## 3. 機能

### 3.1 チームとログイン

| 項目 | 中身 |
|---|---|
| チームを作る | チームの名前・**競技**・自分の 名前・ログインID・パスワード。作った人が 最初のトレーナー |
| チームを作れる人 | 運営用の合言葉（`OPERATOR_CODE`）を知っている人だけ。配る段階で だれでも作れるようにする |
| チームに入る | 招待の合言葉 ＋ 名前・ログインID・パスワード。選手として入る |
| 役割 | 選手／トレーナー。トレーナーが ほかの人をトレーナーにする（上限まで） |
| パスワード | ハッシュにして保存。忘れたら トレーナーが 仮のパスワードを出す（メールは使わない） |
| ログイン | 180日そのまま。10回まちがえると 10分待つ |

### 3.2 競技と 記録の仕方

**競技**：チームを作るときに選ぶ（アメフト・野球・サッカー・バスケットボール・バレーボール・ラグビー・陸上・水泳・テニス・その他）。あとから「管理」で変えられる。

- 記録の画面の 部位のボタン（胸・肩・腕・背中・腹・脚・有酸素）の最後に、競技のボタン（例：「アメフト」）が増える
- 競技の欄には **筋トレではなく、その競技の練習** を入れる。最初から用意してあるのは 今は **アメフトだけ**：
  - 本数で数える：カット練・ヒット練・タックル練・ブロック練・スタート練・ルート練・キャッチ練・パスラッシュ練・ボールキャリー練・スナップ練・キック練・アジリティ練・1on1
  - 時間（分）で数える：7on7・スクリメージ・ポジション練
- ほかの競技は、チームで「＋種目」から足していく
- 前の版で 競技の欄に入れていた 筋トレの種目（パワークリーンなど）は、だれも使っていなければ消し、記録があるチームでは そのチームの種目として 脚などの欄へ移す（記録は そのまま）

**記録の仕方**：種目ごとに 1つ持つ。入れる欄・自己ベストの比べ方・グラフが変わる。

| 記録の仕方 | 例 | 入れるもの | 自己ベスト・グラフ |
|---|---|---|---|
| 重さ×回数 | ベンチプレス | kg（なければ自重）・回 | 見つもり1RM（自重は 回数） |
| 回数だけ | 腕立て伏せの代わりなど | 回 | 回数 |
| 本数 | カット練・ヒット練 | 本 | 本数 |
| 時間（秒） | プランク | 秒 | 秒 |
| 時間（分） | 7on7・スクリメージ | 分 | 分（休憩タイマーは 出さない） |
| 距離×本数 | ダッシュ 40m×10本 | m・本 | 合計の距離 |
| 時間・距離（有酸素） | ランニング | 分・km | 比べない |

種目を足すときは、名前と 記録の仕方を選ぶ（有酸素の欄は いつも「時間・距離」）。足した種目は チームのみんなが使える。

### 3.2.1 ポジション

アメフトでは ポジションごとに筋トレメニューが配られることが多いので、選手に ポジションを持たせる。

- ポジションは 競技ごとに決めてある。今は **アメフト**：QB・RB・WR・TE・OL・DL・LB・DB・K/P・その他（ない競技では 聞かない）
- 選手は **最初にログインしたとき** に ポジションを選ぶ（あとから「自分」で変えられる。トレーナーも「チームの管理」で変えられる）
- 名前の横に ポジションの印が出る（タイムライン・コメント・受信箱・メンバー）
- **メンバーの一覧**：ポジションごとに 分けて並ぶ（ポジションの順 → 未設定 → トレーナー）。上のボタンで 1つのポジションに しぼれる
- **メニューの「人を選ぶ」**：ポジションごとに 分けて並ぶ。ポジションの名前を押すと、そのポジションの人を まとめて選べる（もう一度押すと まとめて外れる）
- 表：`User.position`

### 3.3 筋トレの記録

1. 「筋トレ開始！」を押す（上に 筋トレ前の体重を入れられる。入れなくても始められる）
2. 部位（または競技）のボタン → 種目を選ぶ
3. 数字を入れて「追加」→ 1セット記録 → 休憩タイマーが自動で始まる（有酸素は始まらない）
4. 「筋トレを終わる」→ 投稿の画面へ

- **前回の記録**：種目を選ぶと、前回の数字が最初から入っている
- **自己ベスト**：今までのどのセットよりも強いと 印が付く（初めての種目は 付けない）
- **セットを直す・消す**：記録中と、終わってから 投稿する前まで。直すと 自己ベストの印も 付け直す
- **種目ごとのメモ**：付けたい種目にだけ付けられる（例：ベンチプレス「右肩が少し痛い」）。投稿のまとめで その種目の下に出る。全体の話は 投稿の「ひとこと」に書く
- **あとから記録**：7日前まで。日と 時間（分）を入れて始める。休憩タイマーは動かない。体重は入れない。投稿には「10/12（月）の分」と出る
- 1日の区切りは朝4時

### 3.4 休憩タイマーと知らせ方

| しくみ | 中身 |
|---|---|
| 長さ | 最初は ビッグ3：180秒／胸・背中・脚・肩：120秒／腕・腹：90秒／競技の練習：90秒（時間（分）の練習と 有酸素は タイマーなし） |
| 変え方 | ±15秒（15〜600秒）。変えた長さは その人の その種目に覚える |
| 残り時間 | 「終わる時刻」から計算する（ほかのアプリから戻っても ずれない。開き直しても続く） |
| 画面を見ているとき | ピッ×3・帯が赤く光る・ふるえる（Android だけ）。画面は暗くならない |
| 画面を消しているとき | 休憩が始まったときに サーバーへ「終わる時刻」を伝え、その時刻に サーバーから ロック画面へ通知を送る（急ぎの印つき。1分たっても届かなければ捨てる） |

- 画面を見ているときは 終わる3秒前に 通知の予約を取り消す（音と帯で わかるので）
- Render の無料プランが休むのは 15分だれも使わないときで、休憩は長くても10分なので、無料のままでも送れる
- iPhone は ホーム画面に追加したときだけ 通知を受け取れる
- **ロック画面で 残り時間が動く表示**（iPhone のライブアクティビティ）は Web アプリではできない。ストアに出すアプリにするとき（段階8）に作る。そのため、知らせ方は `static/js/notify.js` の 1か所にまとめてある

### 3.5 投稿とタイムライン

**投稿するとき**（筋トレを終わった直後。あとから 自分のページの履歴からも投稿できる）

- 記録の一覧（セットを直せる・種目ごとのメモ）・全体のひとこと・写真4枚まで
- 「投稿しない」も選べる（記録は 自分のページに残る）
- 写真は スマホの中で小さくしてから送る（長い辺1600px の JPEG）。撮った場所などの情報も消える

**投稿したあと**：ひとことの書き直し・写真を足す／外す（くわしい画面の「直す」）。セットの数字は もう直せない。投稿を消しても 記録は残る。

**タイムラインのカード**：名前・時間・ひとこと・1枚目の写真（横長。残りは「＋2枚」）・メニューの名前・記録のまとめ（種目ごとのメモ付き）・スタンプ・💬 とコメントの数。一番上に 配られているメニューの帯が出る。

**くわしい画面**（💬 を押す）：全部の写真・全部のセット・スタンプ・コメントの一覧・下に コメントを書くバー。

**コメント**：だれでも書ける。トレーナーのコメントは うすい赤で 上に出る。コメントに **返信** できる（元のコメントの下に並ぶ。段は1つだけ）。消せるのは 書いた本人とトレーナー（元のコメントを消すと 返信も消える）。

**スタンプ**：👍 🔥 💪 👏 😂 😮。投稿にも コメントにも付けられる。1人1つ（別のを選ぶと入れかわる）。

- 押すと 付く／もう一度押すと 外れる
- **長押し（パソコンは右クリック）か「だれが押したか見る」で、だれが押したかの一覧**（Slack のように、絵文字ごとのタブで見られる）

**写真の保存期間**：投稿の写真は **半年（183日）** で自動で消える。記録・ひとこと・コメント・スタンプは残り、「写真は 保存期間をすぎたので 消えました」と出る。片づけるのは 起動したときと 1日に1回。

**見え方**：投稿と 1人ずつのページ（履歴・グラフ）は チームのみんなが見られる（名前を押す）。メンバーの一覧（タブ）は トレーナーだけ。体重・体脂肪率は 本人とトレーナーだけ。

### 3.6 知らせ

**ベル**（右上。まだ読んでいない数）

| 知らせ | 中身 |
|---|---|
| コメント | 「○○さんが コメントしました」（トレーナーなら「トレーナーの」が付く） |
| 返信 | 「○○さんが あなたのコメントに 返信しました」 |
| スタンプ | 1つの投稿に 知らせ1つ：「いとう さん、さとう さん ほか2人が スタンプを付けました 👍🔥💪」。新しく付くたびに「まだ読んでいない」にもどって 一番上へ。押すと だれが押したかの一覧と「投稿を見る」 |

**プッシュ通知**（アプリを閉じていても届く）：休憩おわり・コメント・返信・新しいメニュー。「自分」タブで オン／オフ と「ためしに送る」。

- 送り先は Apple・Google・Mozilla・Microsoft の通知サーバーだけ受け付ける（ほかのアドレスへ 送らされないように）
- 1人が登録できる スマホ・ブラウザは 5つまで（多すぎたら 古いものから忘れる）

### 3.7 トレーナーの管理画面

**受信箱**：まだ どのトレーナーも見ていない投稿の一覧（写真なし：名前・投稿した時間・ひとこと）。押すと 中身が下から開く。

- 写真・全部のセット・**前回とのちがい**（↑ ↓ →。初めての種目は「初めて」）・このメンバーへの 前回のコメント・コメント
- **よく使う言葉**（トレーナーが自分で登録）をボタン1つで入れる。コメントに返信もできる
- 「送って次へ」「見ただけ」のあとは 次の投稿が そのまま開く

**メニュー**：3.8

**チームの管理**

- 招待の合言葉（作り直せる）・今の人数と上限
- **競技**（変えると 競技の欄の 用意した種目が入れかわる。チームで足した種目は残る）
- メンバー：トレーナーにする／外す・使えなくする・仮のパスワード
- **チームで足した種目**：名前を直す・**まとめる**（例：「ベンチ」を「ベンチプレス」に）
  - 今までの記録（全員分）・休憩の長さ・メニュー・種目ごとのメモが まとめ先に移り、元の種目は消える
  - グラフ・前回の記録・自己ベストが 1本になる（自己ベストの印は 付け直す）
  - 最初から用意した種目は 全チーム共通なので 直せない（まとめ先には選べる）。記録の仕方が ちがう種目どうしは まとめられない
  - **元には戻せない**ので、押す前に確かめる
- よく使う言葉の 登録

**メンバー**（タブ）：最後に筋トレした日・この7日の回数・最近の自己ベスト・7日以上あいている人に印。押すと その人のページ（履歴・伸びのグラフ・体重）。

### 3.8 トレーナーからのメニュー

ふだん スプレッドシートか写真で送られてくるので、**その形のまま 配れる** ようにした。

| 入れるもの | 中身 |
|---|---|
| 名前 | 例：今週の上半身 |
| 期間 | いつから いつまで（最初は 今週の月曜〜日曜） |
| コメント | トレーナーからの ひとこと |
| 写真 | 4枚まで（紙やスプレッドシートの写真）。写真だけでも配れる |
| 種目（なくてもいい） | 記録の仕方ごとの目標：60kg×8回×3セット／10回×3セット／カット練 10本×3セット／7on7 20分×1セット／60秒×3セット／40m×10本×2セット／**有酸素は 30分・5km** |
| 配る相手 | **チーム全員** か **人を選ぶ**（チェックを付けた人にだけ 出て、通知が届く） |

- 配ると、相手の「記録」の画面（と タイムラインの一番上）に出て、通知が届き、「記録」のタブに「新」の印が出る
- 「このメニューで始める」で始めると、種目ごとに 目標と「2 / 3 ✓」の進み具合が出て、目標の数字が最初から入っている。メニューにない種目も 足して記録できる
- 記録中の画面では「今日の記録」の上に メニューが出る（最初は 閉じている。タップで開く／小さくする）
- 期間がすぎると「過去のメニューを見る」に移り、**半年** 見られる。トレーナーの画面には「期間おわり」と付いて残る
- 「配るのをやめる」と 一覧から消えて 写真も消える（そのメニューでやった記録と メニューの名前は残る）
- 投稿には「メニュー：○○」と出る
- 選手には、だれに配ったかは 見せない（トレーナーの画面にだけ出る）

### 3.9 体重・体脂肪率

- 「筋トレ開始！」の上で体重を入れる（なくてもいい）。「自分」タブで 体重・体脂肪率を入れる（片方だけでもいい）
- 1人1日に1つ。入れ直すと上書き。グラフと 最近の記録が出る
- 見えるのは 本人とトレーナーだけ。トレーナーは メンバーの一覧で いちばん新しい 体重・体脂肪率（入れた日も）を見られる
- **書き出し**（トレーナー）：「管理」→「チームの管理」→「体重・体脂肪率を書き出す」で CSV をダウンロード（この1週間／この1か月／全部）。Google スプレッドシートや Excel で開ける
  - 1行目：選手名・記録した日付・体重(kg)・体脂肪率(%)
  - ポジションが切りかわるところに「RB」のような 1行を入れ、その下に 選手ごとの記録（名前順・日付順）
  - その期間に 記録がない選手も 名前だけ 1行出す（入れ忘れが わかるように）。Excel で文字化けしないように BOM を付ける

## 4. 画面

スマホで使うのが中心。下に タブ（タイムライン・記録・メンバー・自分・管理。メンバーと管理は トレーナーだけ）。

**見た目**：白が基調で、黒は文字とタブ、**赤は「ここを見て・ここを押して」だけ**（大事なボタン・自己ベスト・まだ読んでいない数・トレーナーのコメント・休憩おわり）。文字は Noto Sans JP、数字は Barlow Condensed（スポーツらしく）。絵文字のかわりに 線のアイコン。名前の横に 丸いアイコン（名前の1文字目。トレーナーは赤）。休憩タイマーは 黒い帯に 大きな白い数字で、終わると赤くなる。

アプリの名前は まだ決めていないので、上の帯には チームの名前を出す。

## 5. データの形

| 表 | おもな項目 | メモ |
|---|---|---|
| `Team` | name, invite_code, max_members, max_trainers, **sport** | 上限と競技は チームごと |
| `User`（表の名前は users） | team_id, login_id, name, password_hash, role, active, **position** | login_id は アプリ全体で 1つだけ |
| `Exercise` | team_id（用意した種目は 空）, name, part（部位。競技の欄は sport）, **kind**（記録の仕方）, **sport**（競技向けに用意した種目）, preset | |
| `UserExercise` | user_id, exercise_id, rest_seconds | 休憩の長さは 人ごと |

## 8. インターネット上に置く

手順は [SETUP.md](../SETUP.md)。

| サービス | 何に使うか | 無料の枠 | 気をつけること |
|---|---|---|---|
| GitHub | プログラムの置き場 | 無料 | 非公開にする |
| Render | アプリを動かす | 無料 | 15分 だれも使わないと休む（次に開く人は 30秒〜1分待つ） |
| Neon | データベース | 0.5GB | 文字と数字だけなので 何年も足りる |
| Cloudflare R2 | 写真 | 10GB | 登録に クレジットカードがいる。写真は半年で消えるので、自分のチームなら 約2GB で頭打ち |

- 設定（`DATABASE_URL`・`SECRET_KEY`・R2 の4つ・通知の鍵2つ）が 足りないと、Render では **わざと起動を止める**（写真・ログイン・通知が あとで消えるのを防ぐ）
- パソコンの中の記録は インターネット上には移らない（本番は まっさらから）
- 写真は 非公開の R2 に置き、ログインしている 同じチームの人にだけ アプリを通して渡す

**ほかのチームに配る段階では**：Render は有料プラン（月7ドルくらい）にする。R2 は 10GB をこえた分が 1GB あたり 月0.015ドルくらい。人数の上限と 写真の保存期間は、このお金を増やしすぎないためにある。

## 10. 気をつけること

- **チームの壁**：ほかのチームの 記録・写真・メンバーが見えないこと。テストで 全部の道すじを確かめている。道すじを足したら、そのテストも足す
- **配るときに いるもの**：利用のきまり・個人の情報のあつかいの説明（名前・写真・体重をあずかるため）。未成年の選手がいるチームも想定する
- **写真**：ほかの人が写っていることがある。チームの中だけで見ること・外に出さないことを、最初にチームで決めておく
- **秘密のもの**：パスワードはハッシュで保存。接続文字列・鍵・合言葉は GitHub に上げない（`.gitignore` と Render の画面だけ）
- **やめた人**：記録は残して、ログインだけできなくする
- **元に戻せない操作**（種目をまとめる・投稿を消す・メニューの配信をやめる）は、押す前に確かめる
